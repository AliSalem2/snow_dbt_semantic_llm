Olist metrics, in plain language

Ask about orders, revenue, deliveries and customers of a Brazilian marketplace (Sep 2016 to Oct 2018, amounts in BRL). Claude answers only from governed metrics, and every answer shows the SQL that ran.

How an answer is made

  1. Claude picks a defined metric and the dimensions to group by.
  2. MetricFlow builds the SQL from the dbt definitions. Claude never writes SQL.
  3. Snowflake runs it with a read-only role.
